# HaHa Farm — bản chạy local độc lập

Đây là bản mã nguồn dùng trên máy cá nhân, không sử dụng website hoặc database
Cloudflare của chủ dự án.

Trên Windows, xem **HUONG_DAN_CHAY_LOCAL.md** rồi nhấp đúp
**CHAY_HAHA_LOCAL.bat**.

- Địa chỉ local: http://127.0.0.1:8787
- Dữ liệu riêng: thư mục `.local-data`
- Không cần đăng nhập Cloudflare và không cần chạy `wrangler login`
- Lần chạy đầu cần Internet để cài thư viện; các lần sau có thể chạy offline
